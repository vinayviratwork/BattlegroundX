Every System Built from Scratch

No Asset Store game templates — every script written and architected independently.

🌐
Online Multiplayer
Unity NGO 1.8.1 + Unity Relay — host/join via 6-digit code. No IP exposure, works behind NAT/firewalls.
🔐
Server-Auth Combat
All damage server-validated — direction check, ammo check, raycast on server physics. Anti-cheat foundation.
🏃
Full Player Controller
Walk · Run · Sprint · Crouch · Jump · Aim (ADS) · Camera follow. NetworkVariable state sync to all clients.
🔫
3-Weapon System
Assault Rifle · Shotgun · Sniper. Each with ammo, reload coroutine, recoil. All server-validated.
🎬
Animator State Machine
Auto-generated Animator Controller. 10 parameters driven from NetworkVariables — remote players animated too.
💥
Pooled VFX System
VFXManager with object pools (muzzle flash, hit sparks, blood, explosion). Zero GC allocation — critical for Android 60fps.
🗺️
RenderTexture Minimap
Overhead orthographic camera → 256×256 RenderTexture → HUD. Player icons + safe zone ring update live.
🔵
7-Phase Safe Zone
Radius shrinks 160→8 units across 7 phases. Damage escalates 1→20 dmg/sec. Replicated via NetworkVariable.
🎮
Full Match State Machine
Lobby → Countdown → In-Progress → Ended → Return to Lobby. Only server transitions state.
📱
Mobile Input System
Virtual joystick + look pad + all action buttons. Fully integrated with NetworkPlayerController.
⚙️
Settings Menu
Sensitivity (mouse + touch) · Graphics quality · Master/SFX volume. PlayerPrefs persisted. Escape to open.
📶
Live Ping Display
Actual RTT via ServerRpc echo. 5-sample rolling average. Colour-coded green/yellow/red.

Code Sample

Server-authoritative fire validation — NetworkWeapon.cs

[ServerRpc(RequireOwnership = true)] private void FireServerRpc(Vector3 direction, int weaponIndex, ServerRpcParams rpc = default) { if (rpc.Receive.SenderClientId != OwnerClientId) return; if (!_inventory.HasAmmo(weaponIndex)) return; if (direction.magnitude > 1.1f) return; _inventory.ConsumeAmmo(weaponIndex); if (Physics.Raycast(transform.position + Vector3.up, direction, out RaycastHit hit, _weapons[weaponIndex].range)) { hit.collider.GetComponent<NetworkHealth>() ?.TakeDamage(_weapons[weaponIndex].damage, OwnerClientId); FireHitFeedbackClientRpc(hit.point, hit.normal, true); } else FireHitFeedbackClientRpc(transform.position + direction * 50f, direction, false); }

Quick Setup

From clone to playable in 6 steps.

1
Clone
Download the project
git clone https://github.com/vinayviratwork/BattlegroundX.git
2
Open in Unity Hub
Open BattlegroundX_Project/ in Unity 2022.3.62f1 — packages resolve automatically (~5 min)
3
Generate Scene
One-click — creates entire map, networking, HUD, minimap, settings
Tools → Battleground X → Generate Full Scene
4
Setup Audio
Auto-generates 7 procedural WAV clips
Tools → Battleground X → Setup Audio (Procedural)
5
Link Unity Cloud
Enable Authentication + Relay in Unity Dashboard
Edit → Project Settings → Services → Create Project ID
6
Play Test
Press Play → HOST → copy 6-digit code → open second window → JOIN
