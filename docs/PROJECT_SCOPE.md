# Project scope — student prototype

## Goal
Demonstrate a small online third-person battle-royale prototype on Android and Windows.

## In scope for first playable milestone
- Greybox arena
- Network player spawn
- Basic third-person movement
- Hitscan weapon and health
- Safe-zone damage
- Medkit pickup
- Match countdown and winner state
- Relay host/join
- Basic HUD
- Android and Windows builds

## Out of scope for first milestone
- Commercial-grade BGMI-like art
- 100-player matches
- Dedicated server orchestration
- Production matchmaking
- Vehicles, parachute, squads and full inventory
- Anti-cheat and account persistence
- App-store release

## Definition of done for first playable milestone
All tests T01–T14 in `QA_TEST_REPORT_TEMPLATE.md` pass on actual builds, with evidence and no unresolved blocker/critical bugs.
